МАШИНКИ — как запустить онлайн на своём хостинге
================================================

В папке три файла:
  index.html            — сама игра (всё в одном файле)
  database.rules.json   — правила для базы Firebase
  ИНСТРУКЦИЯ.txt        — этот файл

Без настройки игра уже работает «на одном экране» (с друзьями за одним
компьютером или против компьютера). Для онлайна нужна бесплатная база
Firebase — это 10 минут.


ШАГ 1. Создать базу Firebase (бесплатно)
----------------------------------------
1. Откройте https://console.firebase.google.com и войдите Google-аккаунтом.
2. «Создать проект» → любое имя, например mashinki → Google Analytics можно выключить.
3. В меню слева: «Создание» (Build) → «Realtime Database» → «Создать базу данных».
4. Регион: europe-west1 (Бельгия). Режим: «Начать в тестовом режиме».
5. Откройте вкладку «Правила» (Rules), удалите всё, что там написано, вставьте
   содержимое файла database.rules.json и нажмите «Опубликовать».
   (Тестовый режим сам отключится через 30 дней, эти правила — нет.)


ШАГ 2. Вписать настройки в игру
-------------------------------
1. В Firebase нажмите шестерёнку слева сверху → «Настройки проекта».
2. Внизу «Ваши приложения» → значок </> (Веб) → придумайте имя → «Зарегистрировать».
3. Появится блок firebaseConfig. Откройте index.html любым текстовым редактором
   (Блокнот, VS Code), найдите строку «НАСТРОЙКИ FIREBASE» и перенесите значения:

     window.FIREBASE_CONFIG = {
       apiKey: "AIza....",
       authDomain: "mashinki-xxxx.firebaseapp.com",
       databaseURL: "https://mashinki-xxxx-default-rtdb.europe-west1.firebasedatabase.app",
       projectId: "mashinki-xxxx",
       appId: "1:1234:web:abcd"
     };

   Важно: databaseURL обязателен. Если его нет в firebaseConfig, скопируйте адрес
   со страницы Realtime Database (он над деревом данных).
4. Сохраните файл.


ШАГ 3. Залить на хостинг (любой из вариантов)
---------------------------------------------
Самый простой — Netlify Drop:
  1. Откройте https://app.netlify.com/drop
  2. Перетащите туда папку с игрой.
  3. Получите ссылку вида https://что-то.netlify.app — это ваш сайт.

Другие варианты: GitHub Pages, Firebase Hosting, Vercel, любой обычный хостинг —
достаточно загрузить index.html.


ШАГ 4. Играть
-------------
1. Откройте сайт → вкладка «Онлайн» → введите имя → «Создать комнату».
2. Нажмите «Скопировать ссылку-приглашение» и отправьте друзьям.
   Друг открывает ссылку, вводит имя — и сразу попадает в комнату.
   (Или он может ввести 4-значный код на вкладке «Онлайн».)
3. Хозяин комнаты настраивает трассу и жмёт «Старт».
4. Чат — кнопка «Чат» в правом нижнем углу. Окно можно перетаскивать за
   заголовок, сворачивать, а кнопкой со стрелкой — открыть в отдельном окне
   браузера.


Если что-то не работает
-----------------------
• «Онлайн ещё не настроен» — не вписан databaseURL в index.html.
• «База не принимает запись» — не опубликованы правила из database.rules.json.
• У друга не подключается — попробуйте обновить страницу; если сервисы Google
  у него недоступны, поможет VPN.
